# Pairly

Ежедневная игра «найди пары» в Telegram: один расклад на всех, минута на партию, честный лидерборд.

## Что это

Каждый день сервер генерирует новый расклад. Все играют одинаковый, поэтому результаты сравнимы. Очки считает сервер, а не клиент — подделать результат сложно.
