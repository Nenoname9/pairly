# Задачи

## 01. Доска 4×4

**Неделя 1. Цель:** страница с игровым полем, без логики игры.

### Что сделать

1. `index.html`: заголовок, поле из 16 карточек, кнопка «Начать».
2. `styles.css`: сетка 4×4, карточки квадратные, страница центрирована.
3. Карточка — кнопка с символом (эмодзи или буква). Символы пока не прячем.
4. Проверить на ширине 360px.

### Критерии приёмки

- [ ] Открывается через Live Server
- [ ] Ровно 16 карточек, 4 колонки
- [ ] На телефоне ничего не вылезает за экран
- [ ] Нет внешних библиотек и CDN
- [ ] В консоли браузера нет ошибок

### Подсказки

- `display: grid; grid-template-columns: repeat(4, 1fr); gap: 12px;`
- `aspect-ratio: 1;` делает карточку квадратной
- `<button>` уже кликабелен, но логику пока не пишем

### Чего не делать

- Не писать JavaScript.
- Не подключать React, Bootstrap и прочее.
- Не красить всё в радугу: два цвета и один акцент достаточно.
